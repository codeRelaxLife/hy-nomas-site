# hy-nomas.com

Source for [hy-nomas.com](https://hy-nomas.com), an **unofficial** English
resource for Tencent's Hy-Nomas video world model.

This project is not affiliated with, endorsed by, or sponsored by Tencent.
Official repository: https://github.com/Tencent-Hunyuan/Hy-Nomas

This is a static website built with Node.js. Run `npm run build` to generate
the deployable `dist/` directory. Cloudflare Pages can use that command with
`dist` as its build output directory. No Cloudflare token belongs in this
repository.

The Vast.ai affiliate entry is controlled by `status` in `src/data/affiliates.js`.
